Privacy Policy

Last updated: January 9, 2026

BladePeek is a mobile application designed to assist wind turbine technicians in capturing and organizing blade inspection photos and associated metadata. This privacy policy explains how the app handles data.

1. Data Collection

  • Photos: The app captures inspection photos using the device camera. These images remain stored locally on the device.
  • Metadata: BladePeek stores inspection metadata entered by the user (e.g., blade section, chamber, damage type, radius).
  • Inspection date: The app stores the inspection date (format YYYY-MM-DD).
  • Access control: BladePeek uses a Device Registration Code and an RWE Access Code to enable access for authorized users. This information is used only to enable access and is not used for tracking or analytics.
  • Personal information: The app does not collect names, email addresses, technician IDs, or other personal identifiers.
  • Location data: BladePeek does not collect or use GPS or precise location data.
  • Accounts: BladePeek does not create or manage user accounts, and does not offer account registration.
  • Analytics or crash reporting: The app does not collect analytics, usage statistics, or crash reports.

2. Data Storage

  • All inspection data (photos and metadata) is stored locally on the user’s device within the app’s sandboxed storage.
  • No server upload: BladePeek does not upload or sync inspection data to any external servers.
  • The user may choose to manually export or share data using standard iOS features (e.g., the Files app, zip sharing, AirDrop, email, etc.).

3. Data Sharing

BladePeek does not share inspection data with third parties. Specifically:

  • There is no backend server collecting or storing inspection data.
  • The app does not include advertising, analytics, or crash-reporting SDKs.
  • The app does not send inspection data to external AI services or machine learning APIs.

4. User Control and Permissions

  • Users can delete photos and metadata from the app at any time using the app’s built-in tools.
  • Users can export their data in the form of folders, CSV logs, and image files using standard iOS sharing options.
  • Camera access is requested only when capturing photos, solely for the purpose of taking inspection images. Users can revoke this permission at any time via iOS Settings.

5. Security and Offline Use

  • BladePeek is designed for secure, offline use. No data leaves the device unless the user explicitly chooses to export it.
  • BladePeek does not track users across apps or websites and does not use advertising identifiers (such as IDFA).

6. Children’s Privacy

BladePeek is intended for professional use and is not directed to children.
